# Empório Sabor de Casa

Prévia de site institucional com biscoitos artesanais e produtos naturais.

Site estático em HTML e CSS, responsivo, com imagens locais. Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático.

As informações de endereço e horários foram extraídas do material fornecido pela empresa. O link Como chegar abre uma busca no Google Maps.
